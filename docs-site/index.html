🖊️

Monaco Editor

O mesmo editor do VS Code. Syntax highlighting, autocompletar, split editor, Find & Replace e Go to Line.

🔗

SSH / SFTP integrado

Conecta em múltiplas VPS Linux. Explorer de arquivos hierárquico com lazy load, criar, renomear (F2), deletar e duplicar.

🤖

NEX-ALS AI HUB

Chat com streaming para Anthropic, DeepSeek, OpenAI, Gemini, OpenRouter e Ollama. Modo Agente com até 500 ações autônomas.

🚨

Incident Mode

4 painéis simultâneos: diagnóstico IA + Logs + Docker/PM2 + Terminal. Para quando algo quebra em produção.

🚀

Deploy Assistant

Descreve o deploy em linguagem natural. IA gera plano com comandos e risco. Executa passo a passo com rollback automático.

🔔

Notificações de sistema

Alertas nativos quando disco ≥ 85%, CPU ≥ 90% ou RAM ≥ 90% — mesmo com a janela minimizada.

🌿

Git integrado

Status, diff, stage, commit, push e pull direto no IDE. Sem precisar abrir terminal para operações Git.

👥

Multi-usuário

Autenticação local opcional com roles admin/viewer. Trabalhe em equipe com controle de quem pode modificar configurações.

🔒

Fingerprint SSH

Proteção contra MITM. O fingerprint SHA-256 do servidor é salvo na primeira conexão e verificado em todas as seguintes.

  • Chat IA com contexto do projeto

Instalação

# Opção 1 — Installer (recomendado)

1. Baixe o HEXAGON-IDE-Setup.exe abaixo

2. Execute o instalador

✓ Instalado em %LocalAppData%\NEX-ALS IDE


# Opção 2 — Portable (sem instalação)

1. Baixe o HEXAGON-IDE-Portable.exe

2. Execute diretamente — não precisa instalar


# Requisitos

✓ Windows 10 / 11 (64-bit)

✓ OpenSSH instalado (vem por padrão no Windows 10+)
